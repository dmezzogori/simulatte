# SP4 editor implementation evidence

Status: Task 11 editor milestone verified; not final SP4 acceptance. Branch
`feature/sp4-design`, following transport commit `fd5591f`.

## Implemented

- Typed parameter drafts/forms, exact integer and finite-number parsing, 63-bit
  decimal seed, stopping policy, trace level and KPI controls. Missing required
  strings remain distinct from explicitly empty strings. Source-schema changes
  preserve drafts and require revision review; incompatible values stay invalid.
- SP2 schema-driven structured layout controls, canonical schema validation,
  guarded field-patch undo/redo, explicit map reassignment, Reset and `$unset`.
  Arrays replace wholly; lane vertex ids are preserved on insertion/removal.
- Reused Scene renderer/camera with an editor pointer API, static ghost geometry,
  multiselection, snapping, numeric movement and rotation, and placement/port/
  vertex/node/blocked-area handles. Pointer movement draws imperatively; a
  pointer-up is one draft edit. Generated-id eligibility stays authoritative in
  Python: presentation overrides warn, physical overrides fail validation.
- Bounded/paged controls and provenance display. History retains at most 64
  entries and 32 MiB, and verifies touched fields against the latest revision.
- Physical preview reuses a fresh normal worker and durable INITIAL barrier in
  a disposable coordinator/store, then cancels without acknowledging readiness.
  It never steps the simulation, writes a working layout, changes the project's
  revision, or publishes a simulation result. One concurrent preview slot;
  source/revision change and shutdown cancel it. See D89.
- Authenticated HTTP validation supports the 16 MiB layout cap independently of
  the 256 KiB websocket control cap, preserving exact Origin and revision checks.

## Findings from verification

The first blocked-preview deadline test exposed a polling bug: an expired overall
preview deadline was caught as an ordinary short wait timeout. Moving the overall
deadline check outside that catch fixed termination; the expanded timeout and
process cleanup tests then passed.

Canvas eligibility must not reject all generated-id geometry edits: geometry can
be presentation-only. The canvas now retains the draft with a warning and uses
Python's recorded dependency closure to decide whether persistence is allowed.

A click on an off-grid handle must not snap it merely by selecting it. A small
pointer movement threshold separates selection from a drag gesture.

A redundant same-revision refresh initially cleared a successful preview message
immediately. Preserve the validation result until the draft or authoritative
revision changes. Browser checks also exposed ambiguous accessible names on
schema-variant selectors; these now have explicit labels.
