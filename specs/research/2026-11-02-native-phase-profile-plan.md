# Managed native workflow phase profile

Davide authorized the recommendation with “Proceed”. Measure preparation, input
generation, execution, state capture and publication for the existing supported
backend slice. Preserve fresh processes, readiness, native state fingerprints,
result integrity and reproduction. No optimization, packaging, broader actors,
remote execution or push is included in this gate.

1. Add research-only timing probes to disposable copies of the trusted runtime
   and research project. Keep production sources and native C unchanged. Use
   checked AST transformations, freeze the resulting runtime/source bytes, and
   toggle measurement through private child configuration outside request identity.
2. Measure coarse wall-clock spans and aggregate repeated backend/Python-boundary
   calls. Record inclusive and exclusive durations per thread. Keep diagnostics
   outside artifacts, traces, fingerprints and result publication. Do not add
   nested or cross-process durations to derive whole-process percentages.
3. Validate the timer with a deterministic clock, exact target matching and
   exception/nesting/thread tests. Compare original, dormant and active probes on
   shared results/native state; compare ordinary fingerprints/artifact hashes
   between active/dormant copies with identical source/runtime identity. Reproduce
   ordinary requests using active probes and check isolation/ready ownership.
4. Run the prior two-backend, two-producer, 5k/20k, three-repeat matrix with probes
   active and dormant. Measure outer process wall time independently to quantify
   instrumentation cost. Freeze raw per-process diagnostics and source/assets.
5. Audit accounting, output equality and evidence identity. Report dominant costs,
   uncertainty and a focused next optimization proposal. Commit locally and record
   the findings in Cortex. Do not implement the next optimization in this gate.
