# SP4 live integration verification

Task 12 follows `aeb4eb1`; it does not close SP4 or its release gates. D90 records
the recovery/protocol and presentation export decisions.

The viewer reuses the SP3 imperative controller, panels, renderer and export
clock; the Task 9 incremental reader now feeds them. Presentation overlays are
immutable data separated from the trace. HTML binds them to the unchanged trace
SHA-256. Media dialogs retain their own recording/layout selection. History
selects exact indexed attempts rather than conflating repeated runs at one
input revision. Focus/manual rescan has separate retry semantics. An initially
invalid layout can be repaired with exact-byte backup and revision/file checks.

## Regressions found and corrected

Live notifications exposed a canvas regression: `LayoutDraft.layer` returned a
new clone on every parent render, resetting an in-progress pointer gesture.
A stable deep-frozen render snapshot prevents unrelated-render resets; actual
revision/draft changes still invalidate gestures. A regression test checks
snapshot identity, immutability and edit invalidation.

Linux Firefox exposed a scene ownership bug during lane preview: destroying one
Pixi renderer released global pools still used by another active scene. Scene
teardown now releases global resources only when the last scene is disposed.
The installed Pixi 8.22.0 implementation and primary documentation confirm the
boolean destroy option also releases global resources:
[RendererDestroyOptions](https://pixijs.download/v8.22.0/docs/rendering.RendererDestroyOptions.html)
and [AbstractRenderer source](https://raw.githubusercontent.com/pixijs/pixijs/v8.22.0/src/rendering/renderers/shared/system/AbstractRenderer.ts).
Firefox then passed the full flow, as did source and installed-wheel WebKit.

An earlier installed-wheel WebKit attempt reported a prefix-fetch page error;
it is retained in the diagnostic log rather than counted as passing. Final
source and fresh-wheel runs after scene teardown passed the strict zero-error
assertion. This does not establish an independent cause for that earlier error.

Targeted Python tests also caught a missing test command body and a layout cache
pinned before a revision existed. The fixture and revision-less cache behavior
were corrected; the full gate includes both regression tests.
