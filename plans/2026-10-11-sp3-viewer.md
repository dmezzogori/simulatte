# SP3 Viewer implementation plan

**Status:** approved revision 2, 2026-10-11. Davide approved implementation (“Approved”) after both D9 reviews and correction verification. Implementation and acceptance complete; automated evidence and Davide’s final manual Safari confirmation are recorded below.

**Specification:** [SP3 viewer](../specs/2026-10-11-sp3-viewer-design.md). Base `main` at `632923d` (0.14.0), branch `feature/sp3-viewer`.

**Goal:** A read-only viewer for recorded runs, with accurate playback/inspection, synchronized recorded KPIs, offline HTML and bounded-memory browser video export, shipped in 0.15.

## Constraints

- Preserve core/PyPy usability, trace 1.0/1.1 reading, layout 1.0 semantics, generic delta replay and observer invariance.
- No model execution, layout editing, watching, streaming server, run store, experiments or unrelated fixes.
- Python >=3.11; existing 99% coverage and CI gates remain. Add tests in neighboring test suites for changed behavior.
- Scene/playback/export stay independent of React. One clock; synchronous rendering of prepared data; no clock-driven React state.
- Amendments A1–A3 are accepted (D66–D69). Never silently change a shipped contract or benchmark budget.
- These are implementation units, not instructions to launch workers. Shared trace interfaces must settle before dependent edits.
- Conventional commits when requested; no attribution trailers. Do not merge or release without authorization.

## Task 4: Playback runtime

**Depends on:** 3. **Owns:** `studio/packages/playback`.

**Checks:** deterministic fake-clock and delayed-source tests, same-time sequences, cross-chunk steps, retirement, stale completions, cache eviction, end positions, no activation/kpi-only. Compare all sampled states with `Trace.stateAt` and Python fixtures.

5. Implement explicit resize/context-loss/disposal behavior and texture/geometry reuse. Keep all scene data independent of React.

**Checks:** pure geometry/motion tests; Playwright rendering/picking and tolerant screenshots; direct-seek vs sequential scene equality; 1,000-moving-glyph measurement.
