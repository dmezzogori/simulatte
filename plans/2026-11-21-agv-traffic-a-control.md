# AGV traffic, part A: control — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** approved by Davide on 2026-11-21 together with the design. No task is implemented yet.

**Goal:** AGVs claim nodes, segments and zones ahead of them and wait when a claim is not granted; deadlocks are detected exactly and resolved by a replaceable policy; idle AGVs make way; traffic never fails an order.

**Architecture:** A pure `TrafficNetwork` derives segments, corridors and dead-end branches from the `LayoutGraph` and builds claims. `ReservationController` grants claims, detects deadlocks and calls a `TrafficPolicy`; `FreeFlowController` grants everything. A `TravelExecutor` replaces `FleetCoordinator._travel` and only executes route, claim, move, release. Arcs are still traversed rest to rest in this part; part B changes the motion.

**Stack:** Python 3.11+ standard library, SimPy, the existing event bus, entities and trace; pytest with 99 % branch coverage; TypeScript workspace under `studio/` (pnpm, vitest).

**Spec:** [`specs/2026-11-21-agv-traffic-design.md`](../specs/2026-11-21-agv-traffic-design.md), §5–§8, §11, §12, §13, Appendix A. Signatures below are boundaries, not licence to weaken a contract stated there.

**Follows:** nothing. **Followed by:** [part B, motion](2026-11-21-agv-traffic-b-motion.md), then [part C, routing and release](2026-11-21-agv-traffic-c-routing.md).

## Global constraints

- Branch `feature/agv-traffic` from `main` at `ea1292c`. Conventional commits, one per task, only that task's files. No version bump and no user documentation in this plan; part C owns both.
- Python >= 3.11; CPython 3.11–3.15 and PyPy 3.11 must pass; no new runtime dependency.
- Coverage stays >= 99 % branch for the full suite after every task. `uv run --all-extras ruff check src tests`, `uv run --all-extras ruff format --check` and `uv run --all-extras ty check src` stay clean.
- Every state change is an event emitted behind `if env.wants(Cls): env.emit(Cls(...))`; event construction calls no user code; replaying deltas equals live state at every event.
- Every ordering that decides something is explicit: queues by priority then request counter, entities attached in id order, searches tie-broken by node id. Results must not depend on `PYTHONHASHSEED` or on observers.
- No timer may be scheduled by traffic while the traffic state does not change (spec T23).
- Old names are removed without aliases (spec §14).
- `FreeFlowController` and `ShortestDistanceRouter` are the defaults. `AGVType.length` has no default and is required by `ReservationController`.
- Fixed formats: segment entity id `"<a>~<b>"` with the two node ids in sorted order; corridor id `"corridor:<smallest interior node id>"`; node generated by `subdivide` `"<a>~<b>#<k>"` with `k` from 1, counted from the node with the smaller id.
