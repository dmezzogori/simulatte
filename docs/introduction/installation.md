# Installation

Simulatte requires **Python 3.11 or later** (CI tests CPython 3.11–3.14 and PyPy 3.11, with an allowed-to-fail CPython 3.15 pre-release lane).

Install from PyPI with pip:

```bash
pip install simulatte
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv add simulatte
```

Once installed, continue with [Basic Usage](basic-usage.md) for your first simulation.
