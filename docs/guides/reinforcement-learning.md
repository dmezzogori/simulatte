# Reinforcement Learning

This guide covers wrapping Simulatte simulations as Gymnasium environments for reinforcement-learning experimentation. These APIs live under `simulatte.experimental` and are not yet stable — names and behavior may change between releases.

- [Gymnasium wrapper for RL](../tutorials/gymnasium-wrapper.md): wrap a simulation as a Gymnasium environment for training RL agents.

Looking for warehouse and AGV simulation? That has moved to the [Intralogistics](intralogistics.md) section.
